# Privacy

The skill is an instruction bundle with a server adapter example. It does not include telemetry, a hosted collection endpoint, account credentials, background hooks, or a configured GitHub/Linear workspace. Loading the skill does not execute the adapter or submit feedback.

When your coding assistant uses it, the assistant reads relevant application files under that assistant's permissions and service policies. This project cannot promise that your AI provider processes code locally.

The widget generated in your app is a separate implementation that you must review. Its selected tracker receives the submitted report; your chosen storage provider holds optional media. You control those integrations, credentials, audiences, retention, and notices. The skill's recommended defaults are text-only reporting, diagnostics off, private media, and no notification email in issues.

No report is automatically sent to this skill's author or source repository. Public issue trackers and bearer attachment URLs can expose content; use only when expressly intended. Private workspaces still have their own membership and access policies.

Never submit real secrets or personal/customer data as examples in contributions, public bug reports, screenshots, or webhook fixtures.
